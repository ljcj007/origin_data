# Perfect resonance and fragile localization suppression in correlated disordered chains

This directory accompanies [arXiv:2609.29053](https://arxiv.org/abs/2609.29053).

[Download the manuscript, computational code, input data, and figures](correlated-disorder-transport-code-and-data.zip).

The archive contains:

- `manuscript/`: a combined manuscript and Supplemental Material in PDF and self-contained TeX.
- `code/`: three compact computational entry points, sixteen research computation scripts, a dependency list, and two input datasets used by the interval calculations.
- `figures/`: five vector PDF figures.

The root `README.txt` and `code/README.txt` describe the contents and how to run the scripts. To place the two supplied input datasets in their expected locations, run `python3 prepare_inputs.py` from `code/`. The scripts can generate additional numerical outputs. The archive contains the two specified input datasets and executable calculations; it does not include all raw samples from the paper.
