# Perfect resonance and fragile localization suppression in correlated disordered chains

This directory accompanies [arXiv:2609.29053](https://arxiv.org/abs/2609.29053).

[Download the manuscript, computational code, input data, and figures](correlated-disorder-transport-code-and-data.zip).

The archive contains:

- `论文/`: a combined manuscript and supplement in PDF and self-contained TeX.
- `程序/`: three compact computational entry points, sixteen research computation scripts, a dependency list, and two input datasets used by the interval calculations.
- `图片/`: five vector PDF figures.

The root `说明.txt` and `程序/程序说明.txt` describe the contents and how to run the scripts. The two supplied input datasets can be placed in their expected locations by running `python3 准备计算数据.py` from `程序/`. The scripts can generate additional numerical outputs. The archive contains the two specified input datasets and executable calculations; it does not include all raw samples from the paper.
